Este projeto foi feito para a Atividade de Estudo Programada (AEP) da instituição unicesumar.

Para iniciar o backend, acesse a pasta do mesmo, abra o cmd nela e digite: .\mvnw.cmd spring-boot:run

Para iniciar o frontend, acesse a pasta do mesmo, abra o cmd nela e digite: pnpm dev

Para esta aplicação foram usados alguns arquivos externos, como maven, node.js, pnpm, jdk. 
É recomendado que se tenha estes instalados em sua máquina para que o programa rode sem problemas. 
Caso esteja utilizando VScode, é necessário instalar a extensão do maven no mesmo.
